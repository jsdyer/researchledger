What is in the ledger?

The saved collection keeps 25 Crossref journal-article matches for each Canadian topic query, plus bounded institution queries checked against supplied author affiliations. Results can include tangential matches or work from outside Canada. This is a discovery sample, not a census of Canadian research.

What do the numbers mean?

Publication bars count this view only. Cited-by counts reflect references registered with Crossref and are incomplete; they are not quality scores. Funding and update links appear only when supplied. Missing metadata does not establish that a work has no funding, corrections or retractions.

What is retained?

Weekly captures preserve selected bibliographic fields, counts and links. The app retains 16 captures; older versions remain in repository history. Differences reflect provider metadata or search ranking changes, not necessarily changes to a paper. Your live queries stay in tab memory unless you choose Save current search. Saved searches are stored only in this browser and are not added to the public collection.

This tool provides metadata, not article full text or an assessment of a study's findings. Follow the DOI and publisher to read the work and check its current status. Publication, deposit, index and capture dates describe different events.
